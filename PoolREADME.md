# Pool Game

## What
A full pool table made in Onshape, fully usable.

## How to use

Download the STL file or go to this link to get a file of your choice:

[Onshape Model](https://cad.onshape.com/documents/5d8a72796da5eeec9b446898/w/273eeb60046d05aec3dc36fd/e/0180cd5e4482781c06d30ab9?renderMode=0&uiState=6afa197534d1b0abe680de84)

Then use a slicer like Bambu Studio to slice. Enable supports, and all other default settings will work. Then print and enjoy!!! 

Once you have the print, play and set up using normal pool rules, just on a smaller scale.

## Design

Made entirely in Onshape using common tools.
